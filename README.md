# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/prince12raj/Chat-bot-Agriculture.git
```

---

## Move to Project Folder

```bash
cd Chat-bot-Agriculture
```

---

## Install Requirements

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Project

```bash
python app.py
```

---
